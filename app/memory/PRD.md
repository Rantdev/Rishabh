
# PRD - Chai Maska Bun Amruttulya Franchise Portal

## Problem Statement

Franchise portal displaying Silver (₹99,000), Gold (₹1,29,000), and Platinum (₹2,49,000) packages. Detailed package view modals with high-end images and apply forms. Complete admin login system to change prices, add/remove items, and manage franchise applications. Founders story featuring Shrawan Gupta & Rishabh Gupta from Rewa, Madhya Pradesh. Vibrant Indian tea cafe aesthetic with warm amber, gold, rich chai brown, cream, and smooth animations.

## Core Requirements & Features

1. **Franchise Packages**: Silver (₹99,000), Gold (₹1,29,000), Platinum (₹2,49,000) with detailed inclusions, ROIs, and features.
2. **Detailed Package View**: Clicking any package opens an immersive modal with high-resolution imagery and instant apply form.
3. **Founders Story**: Dedicated story section for Shrawan Gupta & Rishabh Gupta from Rewa, MP, with founder quotes and mission statement.
4. **Admin Panel**: Secure login with credentials (`chaimaskabunn@gmail.com` / `RishabhAndShrawan@20002001`) enabling full CRUD on packages, price updates, item additions/removals, and franchise application review.
5. **Vibrant Tea Cafe Aesthetic**: Crafted with warm amber, gold glowing neon accents, smooth Framer Motion animations, and responsive layouts.

## Architecture

- **Frontend**: React 19, Tailwind CSS, Framer Motion, Lucide icons, Sonner toasts.
- **Backend**: FastAPI with Motor async MongoDB client, Pydantic models.
- **Database**: MongoDB collection for packages and applications.
